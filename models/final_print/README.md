# Final print — ACTIAS_01

`ACTIAS_01_final_print_H2D.3mf` is the Bambu Studio project I actually printed for the final piece
(Bambu Lab H2D, 0.2 mm layers, Bambu Studio 2.8). Open it in Bambu Studio to see every plate.

The flower was printed **as one piece** (`P00` one-piece corolla), not as separate petals.
The right wing (`B02`) is the same model as the left wing (`B01`).

| Part | What it is |
| --- | --- |
| P00 | One-piece flower corolla (final, side ring closed) |
| B01 / B02 | Left / right wing (same model) |
| B04 ×4 / B05 ×2 | Fixed / moving hinge ears |
| B09 | Butterfly body |
| B10 ×2 | Locating collars for the wooden rod |
| M01 | Lower flower base (holds the servo) |
| M03 / M04 / M05 ×4 | Thin base plate / bottom cover / feet |
| M06 | MG90S servo cradle |
| M08 v3 | Servo horn adapter |
| M09 v2 | Sliding sleeve |
| M10 ×2 | 127 mm reinforcement tubes for the steel-wire pushrods |
| M11 | M3 large washer |
| — | Equal-height open adapter (66.7 mm) |

The STL files in `models/stl/` are the earlier trial / single-part versions.
